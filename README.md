# BeatBayashi

- This repository is the place for questions and reports about BeatBayashi.
  このリポジトリは、BeatBayashi についての問い合わせと報告の場所です。

- BeatBayashi is a drum sequencer with CC0 / MIT-0 sounds and an MIT-0 app.
  BeatBayashiは、CC0 / MIT-0の音源とMIT-0のアプリでできたドラムシーケンサーです。

## Questions and reports / 問い合わせと報告

- Please open an Issue.
  Issue を作ってください。
- Issues are public, so please do not write personal information in them.
  Issue は誰でも読めるので、個人情報は書かないでください。
- Replies may take time, and requests may not be taken up.
  返事には時間がかかることがあり、要望に応えられないこともあります。

  アプリのソースコードは、ここにはありません。
