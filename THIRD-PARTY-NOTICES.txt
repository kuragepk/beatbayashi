Third-party notices for BeatBayashi
========================================

This project bundles no audio recordings, but its web build does bundle code
from the packages below. The list is the set of packages Vite puts into the
production bundle; each licence text is copied verbatim from the package's
own LICENSE file at the installed version. Regenerate with
`node scripts/third-party-notices.mjs`; CI-style check: add `--check`.
(See docs/dependency-licenses.csv for the full dependency ledger.)

Bundled fonts (theme kit, ui-system)
--------------------------------------------------------------------------

The web build copies 18 font files into dist/assets/ for the selectable
themes. They are byte for byte the files in templates/ui-system/fonts/ on the
maintainer's desk; each file's sha256 is in that folder's manifest.json and in
docs/PROVENANCE.md, section 6-2. The fonts are not recordings and
are not app code. Their licences:

* Misaki: misaki_gothic.ttf; free-software licence by Num Kadoma (quoted below); Num Kadoma
* k8x12: k8x12.ttf; free-software licence by Num Kadoma (quoted below); Num Kadoma
* PixelMplus12: PixelMplus12-Regular.ttf, PixelMplus12-Bold.ttf; M+ FONTS licence (quoted below); M+ FONTS PROJECT; Itou Hiroki
* DotGothic16: DotGothic16-Regular.ttf; SIL Open Font License 1.1 (below); The DotGothic16 Project Authors (Fontworks)
